Jawaban Topik 1: 5W Tentang Spring Framework

What (Apa itu Spring?): Spring adalah framework open-source berbasis Java yang digunakan untuk membangun aplikasi tingkat enterprise, web, dan microservices dengan cepat, aman, dan mudah.

Why (Mengapa menggunakan Spring?): Karena Spring menggunakan konsep Dependency Injection (Inversion of Control) yang membuat kode menjadi longgar (loosely coupled), lebih rapi, dan menyingkirkan banyak kode boilerplate (kode berulang) dibandingkan Java EE tradisional.

Who (Siapa pembuatnya?): Awalnya diciptakan oleh Rod Johnson pada tahun 2002 dalam bukunya. Saat ini dikelola dan dikembangkan oleh perusahaan perangkat lunak Pivotal (bagian dari VMware/Broadcom).

When (Kapan dibuat/dirilis?): Versi pertama (1.0) dirilis pada bulan Maret tahun 2004.

Where (Di mana Spring digunakan?): Spring digunakan di sisi Backend (server-side) oleh banyak perusahaan besar dunia (seperti Netflix, Amazon, dll) untuk membuat REST API, aplikasi web MVC, pengolahan keamanan (Spring Security), hingga akses database (Spring Data).
